# Posts

Every increment of Sonder ships with an essay: what we added, what it
does to the simulated world, the computer science underneath, and what
we got wrong. Each post is pinned to a git tag (`post/NNNN`) at the
exact code it describes.

Since card 147 (ADR 0003), every post is a directory with two tracks:

- **`complete.md`** — the full essay, written for a reader comfortable
  with code and unafraid of a hash function. This is the canonical
  version.
- **`simple.md`** — the same post in plain language, about a thousand
  words, no background assumed beyond curiosity. Same facts, same
  numbers, same mistakes admitted; it simplifies by leaving things
  out, never by changing them.

Start wherever you like; each file links to its sibling. If a diagram
can explain an algorithm better than a paragraph, the post carries one
(Mermaid, rendered by GitHub in place).
