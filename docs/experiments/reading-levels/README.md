# Reading-level experiment

An experiment in voice, not a publication. Mike's prompt: the posts can
feel academic — rewrite every published post at four reading levels and
compare, so we can decide what the house voice should actually be.

The originals in `docs/posts/` are untouched. Each post gets a folder
here with four complete rewrites:

| File              | Target reader                                    |
|-------------------|--------------------------------------------------|
| `elementary.md`   | grades 3–5 · ~400–600 words · no jargon, no code |
| `middle-school.md`| grades 6–8 · ~600–900 words · one excerpt max    |
| `high-school.md`  | grades 9–12 · ~900–1200 words · intro-programming reader |
| `graduate.md`     | graduate CS · dense, standard terminology, full technical content |

Ground rules every rewrite followed: no fact, number, seed, or hash may
change; simplification happens by omission and analogy, never
distortion; every level keeps at least one "what we got wrong"
admission; lower levels trade the project vocabulary for plain words.

`ANALYSIS.md` is the cross-analysis: what each level costs and buys,
which posts translated well or badly, and what that suggests about
where the originals sit.
